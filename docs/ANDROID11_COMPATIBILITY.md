# Android 11 兼容性与使用边界

当前验证范围为真实启动的 Android 11 / API 30 云端模拟器，未开展不同品牌手机的兼容性认证。

| 场景 | 云端结果及使用要求 |
|---|---|
| 息屏及非安全滑动锁屏 | 已验证定时触发、点亮、原生锁屏解除，再启动真实飞书到前台 |
| 安全密码锁屏 | 软件拒绝解除，不绕过 PIN、图案、密码或其他安全认证 |
| 已亮屏且解锁 | 观察到系统仅显示闹钟横幅，可能需要点按；不能保证强制切换前台 |
| Doze | 强制 Doze 测试通过；不是自然长时间待机验证 |
| 后台进程回收 | 已验证回收后定时执行；不依赖持续后台轮询 |
| 用户强制停止 | 系统会取消任务，需重新打开应用恢复 |
| 开机恢复 | 已验证保留原数据的模拟器冷启动、开机广播及下一次定时恢复 |
| 多时段及总开关 | 已验证多次执行、修改取消旧任务、关闭取消、重新开启恢复及避免重复 |
| 覆盖安装 | 正式签名 APK 已验证覆盖安装后配置保留、更新广播及定时恢复 |
| 通知与电池策略 | 需允许闹钟通知、锁屏显示及必要的后台运行；不同设备的自启动、后台冻结、省电限制仍需实际确认 |

默认无需无障碍服务。应用不读取飞书内容、不截图、不点击考勤、不联网、不模拟定位。应用默认日志只能确认启动请求；云端使用 ADB 独立确认真实飞书前台，未登录账号或核验考勤。

首次安装先配置通知及电池权限，点击 15 秒延迟测试后息屏，确认完整流程后再启用长期定时。失败优先导出诊断日志，不要求反复卸载和安装开发版。

原始 ADB、Logcat、Instrumentation、静态检查及系统快照见 FeishuWake-cloud-evidence.zip。重启时宿主模拟器进程退出后，脚本重新冷启动同一 AVD，未清空数据、未重装或手动打开应用，并核验 kernel boot_id 变化和后续定时执行。
