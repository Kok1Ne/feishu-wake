# Feishu Wake 使用说明

适用目标：realme GT 大师探索版、realme UI 2.0、Android 11。云端验证使用 Android 11 模拟器，realme 厂商兼容性仍需首次安装后验证。

## 首次安装与一次验收

1. 安装正式签名的 FeishuWake-1.0.0.apk，首次打开时保持“自动化总开关”关闭。
2. 确认手机已安装飞书并由您正常登录；本软件不保存飞书账号，也不点击打卡。
3. 当前锁屏必须是非安全的滑动锁屏。若仍有 PIN、图案、密码或其他安全认证，软件会停止解锁流程并记录失败，不绕过认证。
4. 打开“通知与锁屏显示设置”，允许本应用通知，允许“定时唤醒”通知在锁屏显示及弹出。Android 11 不需要额外的“精确闹钟”特殊权限；较新系统的权限按钮不代表已经完成对应系统兼容性验证。
5. 通过“电池优化设置”将本应用设为不优化。若 realme 系统提供自启动、允许后台运行、关联启动或后台冻结控制，请允许 Feishu Wake 正常启动和运行；也检查飞书是否被禁止启动。具体菜单以手机为准，这些厂商设置尚未经目标真机核实。
6. 点击“立即测试（15 秒后执行，请息屏）”，随后按电源键关闭屏幕。等待自动亮屏、解除滑动锁屏、飞书出现在前台。
7. 仅在这个流程成功后，设置所需星期及时间，打开自动化总开关。以后按固定配置持续执行，直到您关闭。

不需要给电脑安装 ADB、连接调试线、开启 Root 或开启无障碍服务。

## 日常设置

- “执行星期”可多选；一个时间适用于所有选中的星期。
- 可添加多个时间，也可删除。重复时间不会添加两次；启用时必须至少保留一个星期和一个时间。
- 修改后会取消旧闹钟并重新计算下一次。时间按手机当前时区解释。
- 固定时刻使用系统可见的闹钟，系统状态栏或锁屏可能显示下一次闹钟时间。这有助于避免普通精确闹钟被待机配额延后。
- 关闭自动化会取消后续定时及待执行的单次测试；“取消当前执行（保留定时）”只取消当前/单次测试，保留以后定时。
- 15 秒单次测试使用允许空闲状态触发的精确闹钟。Doze 下短时间连续测试可能受到系统频率限制，首次完整测试即可。
- 唤醒交接完成后不关闭飞书，熄屏由系统正常超时策略决定。

## 日志与失败处理

软件把几个状态分开记录：

| 日志 | 含义 |
|---|---|
| trigger / OK | 闹钟已被本应用收到 |
| screen / OK | 系统报告屏幕可交互 |
| keyguard / OK | 系统确认无锁屏或已解除滑动锁屏 |
| launch / REQUESTED | 已发送启动飞书请求 |
| foreground / UNKNOWN | 没有足够权限/证据直接确认另一个应用的前台 |
| foreground / OBSERVED | 可选使用情况访问观察到前台事件，仍不代表打卡成功 |
| FAIL / SKIPPED / CANCELLED | 失败、未执行或取消，查看同次运行的前序原因 |

默认无需“使用情况访问”权限；可选开启后，程序只用目标包名相关的恢复事件辅助判断，不读取消息、联系人或考勤页面，也不上传数据。

如果首次测试失败，打开 Feishu Wake，点“导出诊断日志”保存 JSON 文件，提供该文件及大致失败时间。优先根据其中的通知状态、电池优化、锁屏状态、下次任务和每个步骤日志定位；无需反复截图、卸载或安装开发版。

## 已知边界

- 已亮屏且解锁时，系统可能只显示闹钟横幅，需要点按通知；不能保证任何屏幕状态都强制抢占前台。
- 系统回收进程与用户“强行停止”不同。强行停止后闹钟会被取消，需重新打开本应用恢复；不会补执行已经错过的任务。
- 重启和软件覆盖更新会重新安排下一次未来任务。若设备保留安全密码，开机后仍需您先解锁。
- 强制 Doze 模拟器测试不等于自然长时间待机；realme 后台冻结、自启动及厂商锁屏行为仍待最终真机确认。
- 本软件仅唤醒、解除非安全锁屏并打开飞书。飞书是否完成极速打卡由飞书自身条件决定。

## 后续更新

包名固定为 dev.feishuwake，正式版本使用固定签名证书。以后应直接覆盖安装正式更新，避免卸载清空配置。签名恢复资料属于私密资料，请勿放入公开仓库或发给他人。

## realme 官方设置参考

realme 官方帮助列出 UI 2.0 的后台应用锁定方式：最近任务中打开应用右上角菜单，选择锁定；省电模式位于“设置 → 电池”。官方还列出“设置 → 电池 → 更多电池设置 → 优化电池使用”。这属于设置参考，不是本机验证结果；不同地区的中文菜单可能不同。

长按 Feishu Wake 图标进入应用信息，在耗电管理中检查允许后台活动、允许自启动和允许启动其他应用。这些开关对唤醒及启动飞书有影响，仍需以目标手机实际菜单和日志确认。
