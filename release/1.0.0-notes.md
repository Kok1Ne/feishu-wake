Feishu Wake 1.0.0：按选定星期及多个固定时间执行息屏唤醒、解除非安全滑动锁屏并打开飞书，持续运行直到关闭自动化。

适用和已验证系统：**Android 11 / API 30**。

### 下载与首次使用

下载附件 **FeishuWake-1.0.0.apk** 安装，配置通知与电池权限后，点击“立即测试（15 秒后执行）”并息屏。确认自动点亮、解除滑动锁屏、飞书出现在前台，再开启长期定时。详细步骤见附件 USER_GUIDE_ZH.md；失败先导出应用诊断日志。

### 使用边界

- 云端模拟器通过不代表所有手机均已完成兼容性测试；不同设备的后台冻结、自启动、电池及锁屏策略仍需首次安装确认。
- 已亮屏且解锁时可能只显示通知横幅，需要点按。
- 强制 Doze 不等于自然长时间待机；重启验证采用保留原数据的模拟器冷启动，已核验开机广播、配置及后续定时。
- 用户强制停止后需重新打开应用恢复任务；不绕过安全密码。
- 本软件不联网、不读取飞书内容、不点击考勤；飞书前台不代表打卡成功。
